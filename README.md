# 🎲 Ular Tangga Modern — Couple, Classic & Online LDR

Game Ular Tangga interaktif berbasis web dengan desain modern (*glassmorphism*), **40 kartu Deep Talk & Truth/Dare realistis**, pembuat karakter kustom + upload foto pion bulat, musik latar (*Web Audio API*), serta dukungan main bareng **Online LDR (Real-Time)** maupun **Lokal (1 Perangkat)**.

## 🚀 Cara Cepat Memainkan & Menginstall
### Opsi 1: Main Langsung Tanpa Install (GitHub Pages)
1. Buka link live: **`https://rafiabdillah.github.io/ular-tangga-modern/`**
2. **Install ke Layar Utama HP / Desktop:**
   - **Android / Chrome / Edge:** Klik ikon **Install / Tambahkan ke Layar Utama** pada menu browser.
   - **iPhone (Safari):** Ketuk tombol **Share** → **Add to Home Screen**.

### Opsi 2: Jalankan di Komputer Lokal (Windows)
1. Download ZIP dari halaman **Releases** atau clone repository ini.
2. Klik ganda file **`Play-Game.bat`** untuk langsung membuka game di browser default.
